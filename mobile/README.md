# 📱 Bagimu Negriku Market (BN Mart) - Mobile POS

Aplikasi Point of Sale (POS) & Sistem Informasi Keuangan untuk **Bagimu Negriku Market (BN Mart)** berbasis Flutter dengan 3 role: **Kasir**, **Admin**, dan **Owner**.

## 🚀 Fitur Utama

### 🛒 Kasir
- Katalog & pencarian produk real-time
- Keranjang belanja dengan quantity controller responsif
- Perhitungan pembayaran tunai & uang kembalian otomatis
- Pencetakan struk thermal Bluetooth (BLE) 58mm & 80mm
- Salin teks struk instan untuk dibagikan via WhatsApp/SMS
- Pengaturan identitas toko & struk langsung di aplikasi

### 📦 Admin
- Manajemen katalog produk & kategori
- Pembelian barang masuk dari distributor
- Pencatatan penyesuaian stok keluar (rusak, expired, lainnya)

### 📊 Owner
- Laporan laba/rugi bulanan dengan grafik harian
- Ledger riwayat pergerakan stok real-time

## 🛠️ Cara Menjalankan

```bash
# 1. Jalankan backend Laravel di http://127.0.0.1:8000
# 2. Masuk ke folder mobile
cd mobile

# 3. Jalankan aplikasi
flutter run
```
